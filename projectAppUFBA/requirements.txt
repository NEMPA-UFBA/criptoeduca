# padrão do Python.
#
# Versões fixadas, não ">=", porque este arquivo existe para resolver um
# problema prático: o app só rodava na máquina onde foi testado, porque nada
# declarava o que instalar. Fixar garante que quem rodar obtenha o mesmo
# ambiente que foi verificado. O custo é que uma correção de segurança do
# Streamlit ou do bcrypt exige editar este arquivo — o que é uma linha.
#
#   python -m pip install -r requirements.txt
#   python -m streamlit run app.py
#
# Detalhe de versão: streamlit 1.64 exige Python >= 3.10. O ambiente em que
# isto foi verificado usa Python 3.14.
