# Dependências do EduStream.
#
# Cinco dependências usadas diretamente: Streamlit (interface), bcrypt
# (senhas), cryptography (AES-128-GCM do laboratório), psycopg2-binary
# (driver PostgreSQL) e python-dotenv (carrega o .env local). O PDF usa o
# leitor nativo do navegador dentro de um iframe, sem componente extra.
# Todo o resto do projeto (hmac, hashlib, ipaddress, re, threading, time,
# datetime, collections) é da biblioteca padrão do Python.
#
# Versões fixadas, não ">=", porque este arquivo existe para resolver um
# problema prático: o app só rodava na máquina onde foi testado, porque nada
# declarava o que instalar. Fixar garante que quem rodar obtenha o mesmo
# ambiente que foi verificado. O custo é que uma correção de segurança do
# Streamlit ou do bcrypt exige editar este arquivo — o que é uma linha.
#
#   python -m pip install -r requirements.txt
#   python -m streamlit run app.py
#
# Detalhe de versão: streamlit 1.64 exige Python >= 3.10. O ambiente em que
# isto foi verificado usa Python 3.14.

streamlit==1.64.0
bcrypt==5.0.0
